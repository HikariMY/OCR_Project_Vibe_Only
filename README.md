# OCR แปลภาษา — Claude AI

โปรแกรม OCR + แปลภาษาส่วนตัว ใช้ Claude Vision API อ่านข้อความจากภาพ และแปลเป็นภาษาไทย

## การติดตั้ง

```bash
pip install -r requirements.txt
```

## การใช้งาน

```bash
python main.py
# หรือดับเบิลคลิก run.bat
```

1. ใส่ **Anthropic API Key** แล้วกด **บันทึก**
2. เลือกภาพด้วยวิธีใดวิธีหนึ่ง:
   - **📷 จับภาพหน้าจอ** — ลากเมาส์เลือกพื้นที่
   - **📁 เปิดไฟล์ภาพ** — PNG, JPG, BMP, TIFF, WebP
   - **📋 วางคลิปบอร์ด** — คัดลอกภาพแล้ววาง
3. กดปุ่ม:
   - **🔍 OCR** — อ่านข้อความอย่างเดียว
   - **🌐 แปลข้อความ OCR** — แปลข้อความที่อ่านได้
   - **⚡ OCR + แปล** — ทำทั้งสองในครั้งเดียว

## ภาษาที่รองรับ
- อังกฤษ → ไทย
- ญี่ปุ่น → ไทย
- จีน → ไทย / เกาหลี → ไทย (และอื่นๆ)

## หมายเหตุ
- API Key จะถูกบันทึกใน `config.json` (ไม่ถูก commit ขึ้น git)
- ไม่ต้องติดตั้ง Tesseract — ใช้ Claude Vision แทน
